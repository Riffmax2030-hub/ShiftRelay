The same ShiftRelay app detects when it is running on a Gate Tablet. Once unlocked with the Company Code and Owner Email OTP, it stays locked to the Gate Scanner screen where workers tap their NFC ID card or scan the 60-second rotating QR code.

  1. Enter Company Unique Gate Code (`SR-GATE-*`) + Admin Email.
  2. Approve 6-digit verification code sent via Email Auto-Station.
  3. Tablet displays 60-second rotating TOTP QR + NFC tap reader.
  4. Workers tap encrypted DESFire NFC badge to clock in/out in 0.3s.
  5. Exiting Kiosk mode requires Owner/Admin verification code.
