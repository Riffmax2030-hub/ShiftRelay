## ☁️ 3. Production Cloud Hosting & Deployment Guide (`[RIFA-15]` — Farouk Bello, Tariq Al-Hassan & Chidinma Okonjo)

ShiftRelay OS is pre-configured with [`Dockerfile`](file:///c:/Users/DATA%20ENG.%20OLA/Documents/openAI%20build%20week/Dockerfile) and [`render.yaml`](file:///c:/Users/DATA%20ENG.%20OLA/Documents/openAI%20build%20week/render.yaml) for zero-downtime cloud deployment.

### Option A: 1-Click Render / Railway Cloud Deployment
1. Push this repository to your GitHub organization (`Riffmax2030-hub/ShiftRelay`).
2. In **Render** (`dashboard.render.com`) or **Railway** (`railway.app`), click **New Blueprint / Deploy from GitHub repo**.
3. [`render.yaml`](file:///c:/Users/DATA%20ENG.%20OLA/Documents/openAI%20build%20week/render.yaml) automatically provisions:
   - **Web Service (`shiftrelay-web`)**: Node 22 production server running `npm start` (`node server.mjs`) with health check on `/api/health`.
   - **Environment Variables**:
     - `NODE_ENV=production`
     - `APP_URL=https://app.shiftrelayos.com`
     - `SESSION_SECRET` (auto-generated 256-bit secret)
     - `DATABASE_URL` (connect to Managed PostgreSQL / Neon / Supabase for persistent multi-tenant storage)
     - `GEMINI_API_KEY` / `OPENAI_API_KEY` (optional for live AI handover summarization)

### Option B: Custom Domain & Cloudflare SSL Setup
Configure your DNS records in Cloudflare for `shiftrelayos.com`:
- `A / CNAME @` → Points to your cloud host (`shiftrelayos.com/website.html` serves as the corporate marketing site).
- `CNAME www` → Points to `shiftrelayos.com` (`www.shiftrelayos.com`).
- `CNAME app` → Points to the same unified deployment (`app.shiftrelayos.com` serves the mobile/API PWA).
- `CNAME admin` → Points to `admin.shiftrelayos.com` (`/admin.html` Sovereign & Staff Admin Console).
- Transactional email station records for `mail.shiftrelayos.com` (`SPF`, `DKIM`, `DMARC`, `MX`).
- Set Cloudflare SSL/TLS mode to **Full (Strict)** and enable **Always Use HTTPS**.
